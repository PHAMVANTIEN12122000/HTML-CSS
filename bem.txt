#1: BEM Khái niệm.
 
 Viết tắt của : BLOCK - ELEMENT - MODIFIER 
  
  - Block    :  Khối .

  - Element  :  Thành phần trong khối.

  - Modifier :  [ ***** Bổ sung ý nghĩa ***** ] cho [ Block ] hoặc [ Element ] .



#2: Luồng tư duy :

  #2a: Dùng [ Block ] and [ Element ] + CSS  -- > tạo ra khối cơ bản [ Trạng thái bình thường ] .
  
  #2b: Thêm 1 Class mới [ Modifier ] thêm vào thành phần khối [ Block ] and [ Element ] có sẵn . 
       sau đó thêm vào cạnh class [ Block ] and [ Element ] ==> Tác dụng thêm sự thay đổi . [trạng thái, màu, kích thước, ..]



#3: Tại sao lại dùng BEM.
 
 - Mỗi người đặt một kiểu --> khó quả lý code.

 - Menbers đặt class trùng nhau --> CSS đè lên nhau. Ông mới code hỏng code ông cũ.



#4: Cú pháp BEM.
 
 - .block

 - .block__element 

 - .block--modifier

 - .block__element--modifier



 #5: Khi nào dùng modifier 

 - Có thể sử dụng Modifier để :
    
    + thay đổi kiểu giao diện  :
       
       -  Kích thước.

       -  Màu sắc.

       -  Kiểu chữ.

       -  Font chữ 

       -  Độ rộng.

       -  Độ cao. 

       -  v.v. của các phần tử.

    
     + Thay đổi trạng thái tình huống :
       
       - error

       - warning 

       - success 



#6: Block lồng nhau.
 
 #6a: Block con là thành phần dùng chung.
     
      - Coi đó là 1 Block mới , ko coi nó là 1 Element của Block cũ nữa.

      - Khắc phục tạo class dùng chung khi tạo style của nó.



  #6b: Block con chứa nhiều Element .
      
      - Ý tưởng tách ra từng Block để đặt tên.

      - Tách nó làm Block mới nâng cấp từ   Element -> Block.


#7: khi nào sử dụng Modifier.

    - 1. Thay đổi giao diện : Màu Sắc , Kích thước , Kiểu dáng...

    - 2. Thay đổi trạng thái khác nhau : Hoạt động(--active, --enabled) , Vô hiệu hóa(--disabled), Được chọn (--active) , Bỏ chọn(--inactive)...

    - 3. Thay đổi các biến thể chức năng : 

      + Nút Khác nhau : Submit, delete, cancel, sign in, sign up .....
      + Các kiểu Thông báo khác nhau : Success, Error, warning.....
      + Các loại thẻ giá khác nhau : Giảm giá, Hàng mới, hết hàng.....
      + Các loại bài viết trong Blog : Phổ thông, đặc biệt, Quảng cáo.....
      + Các kiểu bố cục lưới : 2 cột , 3 cột , 4 cột.....

    - 4. Khi cần tạo các biến thể về bố cục : Điều chỉnh lề hoạc căn chỉnh của 1 phần tử.


=> Modifier được sử dụng khi : Cần thay đổi :  giao diện, trạng thái, chức năng, Bố Cục,... 
      của 1 Block hoặc Element mà KHÔNG LÀM THAY ĐỔI CẤU TRÚC HTML
